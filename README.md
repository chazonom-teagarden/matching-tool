# 社内マッチングツール

社内交流促進のためのペアマッチングツールです。

## 使い方
1. Googleスプレッドシートのデータを全選択してコピー
2. ツールの入力欄にペースト
3. 「マッチング実行」をクリック

## マッチングパターン
１）拠点が東京同士のペア、かつ 入社年が2年差以上、かつ趣味が同じ、ただし所属チームは異なる
２）拠点が大阪同士のペア、かつ 入社年が2年差以上、かつ趣味が同じ、ただし所属チームは異なる 
３）拠点が異なるペア、かつ趣味が同じ、ただし所属チームは異なる
４）拠点は不問、職種が同じ、ただし所属チームは異なる

## 空欄データの扱い
`last_name_ja`・`first_name_ja`・`location_name`・`team_name`・`join_date` が空欄でもスキップせず、マッチング対象に含めます。
- `join_date` が空欄 → 入社年差の条件は不問（常にOKとして判定）
- `location_name` が空欄 → 拠点が異なる（③パターン）側として扱う
- `team_name` が空欄 → 別チームとして扱う
該当者は画面上に警告として表示されます。

## 除外設定（任意）
- 除外するメンバー：退職予定者・休職者など、マッチング対象から完全に外したい人を指定できます
- 除外するペア：特定の2人だけを組ませたくない場合に指定できます

## データについて
入力データはブラウザ内のみで処理され、外部サーバには送信されません。
