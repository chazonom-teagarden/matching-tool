# 社内マッチングツール

社内交流促進のためのペアマッチングツールです。

## 使い方
1. Googleスプレッドシートのデータを全選択してコピー
2. ツールの入力欄にペースト
3. 「マッチング実行」をクリック

## マッチングパターン
１）拠点が東京同士のペア、かつ 入社年が2年差以上、かつ趣味が同じ、ただし所属チームは異なる
２）拠点が大阪同士のペア、かつ 入社年が2年差以上、かつ趣味が同じ、ただし所属チームは異なる 
３）拠点が異なるペア、かつ趣味が同じ、ただし所属チームは異なる
４）拠点は不問、職種が同じ、ただし所属チームは異なる

## データについて
入力データはブラウザ内のみで処理され、外部サーバには送信されません。
