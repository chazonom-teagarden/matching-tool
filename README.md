# 社内マッチングツール

社内交流促進のためのペアマッチングツールです。

## 使い方
1. Googleスプレッドシートのデータを全選択してコピー
2. ツールの入力欄にペースト
3. 「マッチング実行」をクリック

## マッチングの条件
絶対条件は「所属チームが異なること」のみです（入社年差・趣味・職種の共通は判定条件には使いません）。

拠点によって以下の4カテゴリに分類し、表示します（優先順位には影響しません）。
１）①東京同士のペア
２）②大阪同士のペア
３）③拠点が異なるペア（拠点またぎ）
４）④その他拠点同士のペア（東京・大阪以外の同拠点ペア）

マッチ理由は、タグの登録数による機会の不平等を避けるため、必須条件ではなく次の優先順位で付与します。
1. 趣味が1つ以上共通 →「趣味：〇〇」
2. （趣味共通なしで）職種が1つ以上共通 →「職種：〇〇」
3. どちらもなし →「共通点なし（チーム違いのみ）」

## 空欄データの扱い
`last_name_ja`・`first_name_ja`・`location_name`・`team_name`・`join_date` が空欄でもスキップせず、マッチング対象に含めます。
- `join_date` → 判定には使用しません（表示のみ）
- `location_name` が空欄 → 拠点が異なる（③パターン）側として扱う
- `team_name` が空欄 → 別チームとして扱う
該当者は画面上に警告として表示されます。

## 除外設定（任意）
- 除外するメンバー：退職予定者・休職者など、マッチング対象から完全に外したい人を指定できます
- 除外するペア：特定の2人だけを組ませたくない場合に指定できます

## 過去のマッチング履歴・毎月の自動選出（任意）
履歴シートから「年月・Aさん・Bさん」のTSVと「対象年月」を入力すると、以下を自動で行います。
- 直近12ヶ月以内にマッチ済みの組み合わせを自動で除外
- 前月マッチ済みのメンバーを自動で除外（2ヶ月連続マッチ防止）
- 「公平性優先で自動選出」ボタンで、①東京同士・②大阪同士・③拠点またぎをそれぞれ最大10組、最後にマッチしてからの経過月数が長い人（未マッチの人を最優先）から自動選出
- 選出結果には「初回」「待機◯ヶ月」のタグを表示し、選ばれた理由が分かるようにしています
- 「履歴追記用TSVをコピー」で、選出結果を履歴シートにそのまま追記できる形式で出力します

## データについて
入力データはブラウザ内のみで処理され、外部サーバには送信されません。
